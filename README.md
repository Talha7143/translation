# 💡 Smart Page Explainer - Chrome Extension

> **Reads any web page, highlights key points right on the page, and explains them in Plain English or 50+ native languages.**

---

## ✨ Features

- 🔍 **Full Page Content Reader:** Smartly extracts the main body, eliminating clutter, ads, navigation bars, and footers.
- 🎨 **In-Page DOM Highlighting:** Automatically identifies the most vital core arguments, findings, and data points, and highlights them directly inside the page without breaking layout or styling.
- 📍 **Interactive Two-Way Navigation:**
  - Clicking any highlighted sentence on the web page jumps right to its breakdown in the explainer drawer.
  - Clicking any card in the explainer drawer smoothly scrolls the web page to the highlight and flashes an emerald glow.
- 🌐 **50+ Native Languages + Plain English (ELI5):**
  - **Plain English:** Simplifies complex academic, technical, or legal jargon into everyday language like you're 12 years old.
  - **50+ Native Languages:** Spanish, French, German, Hindi, Mandarin, Japanese, Arabic, Bengali, Portuguese, Russian, Telugu, Marathi, Tamil, Urdu, Turkish, Vietnamese, Swahili, and 40+ more!
- 🔊 **Native Audio Read Aloud (TTS):** Uses the browser's native Web Speech synthesis to read the summaries aloud in the selected native language!
- ✨ **Selection Quick Explain:** Highlight any paragraph on any page, and a floating `💡 Explain` bubble appears for instant breakdowns.
- 🛡️ **Shadow DOM Architecture:** Injected UI is rendered inside an isolated Shadow DOM container, preventing website CSS conflicts.
- 🤖 **Dual AI Engine:**
  - **Built-in Smart Engine:** Works out-of-the-box instantly with zero setup, extractive sentence scoring, and free translation fallback.
  - **Gemini AI Mode:** Connect a free Google Gemini API key for deep reasoning, analogies, and rich ELI5 summaries.

## 🚀 How to Install in Google Chrome (15 Seconds)

1. Open **Google Chrome**.
2. Type `chrome://extensions` in the address bar and press **Enter**.
3. In the top-right corner, toggle **Developer mode** to **ON**.
4. In the top-left corner, click the **"Load unpacked"** button.
5. Select the extension directory:
   ```
   C:\Users\LENOVO\Desktop\smart-page-explainer-extension
   ```
6. The extension is now installed! Pin it to your Chrome toolbar by clicking the puzzle icon (🧩) next to your address bar.

---

## 🧪 Quick Test / Demo

To see it in action immediately:
1. Open Chrome and press `Ctrl + O` (or drag and drop).
2. Open the included demo article:
   ```
   C:\Users\LENOVO\Desktop\smart-page-explainer-extension\demo\sample-article.html
   ```
3. Notice the floating **💡 Explain Page** pill on the right side of the screen, or click the extension icon in your Chrome toolbar.
4. Click **"Analyze & Highlight"**!
5. Watch the key sentences illuminate on the page and read the Plain English or native language breakdown in the sidebar.

## 🤖 Optional: Adding a Free Google Gemini API Key

1. Right-click the extension icon in your Chrome toolbar and choose **Options** (or click the ⚙️ gear icon in the extension popup).
2. Click the link to [Google AI Studio](https://aistudio.google.com/app/apikey) to generate a free Gemini API key.
3. Paste the API key and click **Save Settings** (or **Test AI Connection**).
4. You now have deep generative AI reasoning with custom analogies on every web page!
